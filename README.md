## 🛠️ Troubleshooting

If the software does not open, check if your antivirus software flagged the installation. Sage uses direct system calls to manage memory. Some security tools might mistake this behavior for a threat. You may need to add an exception for the Sage folder.

Performance issues often link to memory usage. If the AI responds slowly, close other large applications like web browsers or image editors. This frees up the system resources Sage needs to calculate results.

Updates happen through the release page. Check back periodically to download the latest installer. Running the installer over an existing version updates the files automatically. Your settings and project data remain intact during this process.
